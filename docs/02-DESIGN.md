# 02 · Дизайн и «вау»-моменты

Принцип: **один сильный образ, исполненный безупречно**, вместо набора эффектов. Образ — «инженерная ночь»: тёмная сцена, свет рампы на шлифованном алюминии, оранжевая монтажная разметка.

## 1. Токены (из промпта, без изменений)

| Токен | Значение | Роль |
|---|---|---|
| `--color-void` | `#08090B` | фон |
| `--color-carbon` | `#121418` | карточки |
| `--color-grid` | `#22262D` | линии сетки |
| `--color-alu` | `#C9CED6` | основной текст |
| `--color-mute` | `#7D8591` | второстепенный текст (проверить AA на void: ≈ 5.2:1, ок) |
| `--color-signal` | `#FF6A13` | акцент, CTA, разметка |
| `--color-white` | `#F4F5F7` | заголовки |

Шрифты: **Golos Text** (600–700 заголовки, 400 текст), **JetBrains Mono** (серии, размеры, подписи на чертежах). Радиусы 0–4 px, рамки 1 px, сетка 12 колонок, max-width 1440.

Градиенты используем только как свет: луч прожектора, тёплое пятно на металле, оранжевый «жар» на CTA-секции. Никаких фиолетовых градиентов и стеклянных карточек.

## 2. Визуальный язык

- **Чертёж как украшение.** Размерные линии, перекрестия в углах секций, подписи вида `T52 / Q / L=8000`, координатная рейка слева (меняется по мере скролла).
- **Нумерация секций** `01 — 12` моноширинным, как листы чертежа. Штамп (основная надпись) в футере в стиле ГОСТ-рамки: «Лист · Масштаб · Лит.».
- **Hazard-полоса** оранжево-чёрная — максимум в двух местах (граница CTA, плашка «Концепт»).
- **Заглушки** `[...]` — пунктирная рамка, цвет mute, видны намеренно.
- **Фото нет** (нет доступа к стокам из окружения, и клиентских фото тоже нет). Вместо этого: 3D-рендеры из R3F, процедурные SVG-иллюстрации, «плейсхолдер-плёнка»: монохромная подложка с зерном, силуэтом конструкции и подписью `[фото проекта — от клиента]`. Это выглядит намеренно, а не как пустое место.

## 3. «Вау»-моменты (по убыванию веса)

1. **Hero: ферма собирается на глазах.** Пояса выезжают, раскосы «привариваются» по очереди с оранжевой вспышкой на стыке (эмиссия ≤ 30 мс). Поверх — два движущихся прожектора, холодный и тёплый, ферма бликует. Камера реагирует на мышь (±3°). Заголовок выезжает из маски построчно.
2. **Сборка на скролле (pin 250 %).** Та же ферма «взрывается» на элементы с выносными подписями (пояс, раскосы, соединитель, сплав), затем собирается в портал: две опоры и ригель. Это главное доказательство «мы инженеры».
3. **Конфигуратор.** Панель серия/сечение/длина/вид, процедурная ферма перестраивается с каскадной анимацией раскосов, «паспорт» серии моноширинным, кнопка «Запросить расчёт с этими параметрами».
4. **Геленджик Арена (pin 200 %).** Силуэт арены, по скроллу опускается противопожарный занавес, открывается подъёмный люк, подписи Задача → Решение → Результат.
5. **Сценические комплексы СК-1/2/3 в одном масштабе.** Размерные линии прорисовываются, цифры «печатаются».
6. **Микро-слой:** курсор-перекрестие с X/Y (pointer: fine), магнитные CTA, лёгкий дрейф сетки фона, count-up фактов, тикер проектов, прогресс-рейка.
7. **Прелоадер-чертёж** (≤ 1,2 с, один раз за сессию, пропускаемый): сетка и контур фермы прорисовываются линией, затем уходят вверх шторкой. Нужен, чтобы 3D успела догрузиться и первое впечатление было «постановочным».

## 4. 3D-спецификация

- Один «сценический» `Canvas` (hero + сборка на скролле), закреплён `position: fixed`, управляется общим прогрессом скролла. Второй `Canvas` — конфигуратор, монтируется только когда секция близко к вьюпорту. Одновременно не более двух WebGL-контекстов.
- Генератор фермы `buildTruss({ series, section, length })`: пояса — цилиндры/`TubeGeometry` по вершинам сечения, раскосы — `InstancedMesh` зигзагом, торцы — упрощённые конусные соединители. Арочная — по `CatmullRomCurve3`.
- Материал: `MeshPhysicalMaterial` / `MeshStandardMaterial`, metalness 1, roughness 0.28–0.35, лёгкая анизотропия, цвет `#C9CED6`. Освещение: приглушённое окружение (`warehouse`) + два `SpotLight` + оранжевый `PointLight` на сварке. Пол: `ContactShadows` + едва заметное отражение.
- Постпроцессинг (bloom на эмиссию, виньетка) — только desktop, отключается при низком FPS (авто-деградация: `PerformanceMonitor` из drei).
- `frameloop="demand"` вне взаимодействия, `dpr={[1, 1.75]}`.
- **Мобильный сценарий:** до тапа — заранее отрендеренный постер (PNG/WebP из 3D, генерируем сами скриптом) + кнопка «Покрутить в 3D». Сборка на скролле → 3 кадра SVG.
- Фолбэк при отсутствии WebGL / `prefers-reduced-motion`: изометрический SVG той же фермы, параметры конфигуратора работают на нём.

## 5. Типографика

- Заголовок hero: Golos Text 700, `clamp(2.6rem, 7vw, 6.5rem)`, межстрочный 0.95, лёгкое отрицательное трекинг-значение.
- Крупные «числа-факты»: JetBrains Mono, размер до 9rem, оранжевая единица измерения.
- Тело — 17–18 px / 1.6, колонка ≤ 62 символов.
- Утилита `typograph()` для всего текста из `/content` (неразрывные пробелы, «ёлочки», тире, ₽).

## 6. Анимационные правила

Только `transform`, `opacity`, точечно `filter`. Easing `[0.22, 1, 0.36, 1]`. Появление блоков: translateY 24–40 px + blur 6→0, один раз. `prefers-reduced-motion` отключает scrub, параллакс, автодвижение, прелоадер. На < 768 px — без pin там, где мешает.

## 7. Что сознательно не делаем

Светлую тему, переключатель языков, чат-бота, карусели с автопрокруткой на тексте, стоковых людей, чужие логотипы, сравнения с Prolyte/Eurotruss по имени, цены и нагрузки.
