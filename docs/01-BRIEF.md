# 01 · Бриф: МДМ-Технология

Сводка по четырём источникам: промпт «Алексей-3.1», обзор mdmt.ru (21.10.2026), отзывы Яндекс Карт, HTML главной страницы. Архив ai-architect — общая методичка (шаблоны КП, ТЗ, деплой); к этому сайту напрямую не применяется, используем из него только принцип «демо продаёт лучше текста».

## 1. Задача

Сайт-концепт для ООО «МДМ-Технология» (производитель алюминиевых ферм и сцен, Москва). Делаем бесплатно, до первого контакта. Генеральный директор — С. В. Глухов — откроет его с телефона и должен сразу увидеть: это на порядок лучше текущего mdmt.ru.

**Главный критерий успеха — внешнее впечатление.** Приоритет: композиция, типографика, 3D, анимация, ощущение дорогой студийной работы. Глубина внутренних страниц вторична.

Ограничения: статический экспорт (Next.js `output: 'export'`), бесплатный хостинг, noindex, никаких выдуманных фактов.

## 2. Что не так с текущим сайтом (повод для контакта и ориентир для контраста)

- Типовой шаблон Aspro на Битриксе, jQuery 2.2.4, Roboto. «Каталожный» вид 2020 года.
- Шапка перегружена: QR-код, два логотипа, поиск, телефон, кнопка.
- Все 4 слайда hero с одним заголовком «МДМ-Технология».
- Геленджик Арена и другие сильные проекты спрятаны в обычную сетку «Выполненные проекты».
- В SEO-тексте на категории: капс, «ЦЕНА – БОМБА!», «МОНСТРЫ!», «Пишите 24/7» при режиме 9:00–17:30.
- Опечатки: «Корфы и кейсы», «Cветодиодый экран» (латинская C).
- Корзина вместо сценария «запросить КП»; нет конфигуратора и сравнения серий.
- Внутри HTML: в блоке преимуществ ссылка «демонтажные работы» ведёт на сторонний сайт `profrepair.pro` (похоже на проданную SEO-ссылку). В этом документе — только как наблюдение; на сайте-концепте не воспроизводим и в письмо не включаем без решения команды.
- Из кода меню видно: в списке «Продукция» 25 пунктов без иерархии важности.

## 4. Противоречия в источниках (нужны решения, см. `DECISIONS.md`)

1. **Что означает номер серии.** Промпт запрещает читать T23/T29 как миллиметры. Обзор сайта: «квадратные 290×290 мм – T29 Q», основная труба 50×2,5, раскосы 20×2. То есть T29 ≈ сечение 290 мм. Для 3D берём относительные пропорции с подписью «Схема. Размеры условные»; текстом размеры не заявляем, пока не решено.
2. **Набор серий.** Промпт: 7 серий. Сайт: минимум 10 (T36, T62, T158 — дополнительно). Показывать только 7 из промпта или все — решение за заказчиком концепта. По умолчанию: 7, с пометкой «и другие серии каталога».
3. **Цены.** В обзоре есть реальные цены SKU T29 Q. Промпт запрещает выдуманные цены; эти — не выдуманные, но на сайте-концепте цены не показываем (устареют, и это не наша зона).
4. **Строительные леса.** Промпт: «леса рамного типа». Сайт: «клиновые леса типа Layher». Берём формулировку сайта, «Layher» — только текстом, без логотипа.
5. **Год.** 2003 или 2004 — по умолчанию 2004.
6. **Куда уходит заявка.** Промпт: `[почта отдела продаж — уточнить]`. Подставляем публичный info@mdmt.ru и Telegram t.me/mdmtechnology; WhatsApp-кнопки нет.
7. **Цитата Сергея** содержит слово «древние» — обрезаем.

## 6. Аудитория сайта

1. Технический директор прокатной компании → серия под задачу.
2. Закупщик / тендер → сертификаты, ГИСП, реквизиты.
3. Застройщик выставок / ивент → сценические комплексы.
4. Площадка / арена → кейс Геленджик Арены.

И один особенный читатель — **директор завода, который видит себя со стороны**. Для него главное: «это я, только на уровне мировых брендов».
