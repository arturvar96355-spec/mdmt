## Статус реализации (21.10.2026)

Сделано: основа и дизайн-система (`/styleguide`), генератор фермы (7 сечений), hero с 3D-сборкой, прелоадер, сцена «ферма → портал» на скролле, Геленджик Арена на скролле, конфигуратор, каталог с URL-фильтрами, планы СК-1/2/3 в одном масштабе, проекты, производство, отзывы, форма запроса (`mailto:` + Telegram), футер со штампом, `/privacy`, 404, OG, README.

Принятые по ходу решения:
- Заявка без `react-hook-form`: у `@hookform/resolvers` конфликт peer-зависимостей с zod 4, валидация — на zod напрямую.
- Окружение 3D — процедурные `Lightformer`, без HDR-файлов с CDN (стабильно в РФ).
- Сцены на скролле — `position: sticky` + ScrollTrigger scrub (без GSAP `pin`: он ломал размонтирование React).
- Подписи узлов — DOM-слой с проекцией 3D-якорей (drei `Html` падал в React 19).
- На мобильных 3D запускается по тапу «Покрутить в 3D»; сцены на скролле заменены статичными SVG-кадрами.

Не проверено: Lighthouse (нет запуска в окружении), реальный FPS на устройствах (swiftshader), открытие из РФ без VPN.
Не сделано: WhatsApp (у компании нет).

## Обновление: оптимизация и доработка

- Добавлены `/catalog/[series]` (7 статических страниц), `/contacts` (схема проезда), шкала прогресса, лучи прожекторов в hero, ссылки `?cfg=T52.square` в конфигуратор.
- Производительность: появление блоков через общий IntersectionObserver и CSS вместо motion на каждый блок; SVG-ферма в hero рисуется CSS-анимацией; проверка WebGL кэшируется и на телефонах откладывается до тапа; Lenis отключён на тач-устройствах; заставка только на десктопе и не попадает в HTML (флаг ставит inline-скрипт); шрифты — вариативные, по одному файлу.
- Lighthouse (мобильный профиль, headless с программным WebGL): Performance 80–82, Accessibility 100, Best Practices 100. SEO ниже из-за намеренного noindex. На реальных телефонах цифры должны быть лучше, но это не измерено.
- Остаются заглушки: список даёт `npm run placeholders`.

- Добавлены отдельные страницы `/stages`, `/projects`, `/projects/[slug]` (Геленджик Арена — полный кейс, остальные — шаблон с заглушками), `/production`, `/rfq`. На телефоне и при reduced-motion кейс Геленджик Арены показывается в конечном состоянии схемы.
