# 03 · План работ

Приоритет: **первое впечатление**. Фазы упорядочены так, чтобы после фазы 3 уже можно было показать «вау» на телефоне, а всё остальное — наращивание.

## Стек (версии проверены 21.10.2026)

Next.js 16.4.2 (`output: 'export'`), React 19.3, TypeScript strict, Tailwind 4.3, three 0.186, @react-three/fiber 9.8 (peer: React ≥19 <19.4 — совместимо), @react-three/drei 10.7, @react-three/postprocessing 3.2, GSAP 3.15 + ScrollTrigger, Lenis 1.3, motion 14.5, lucide-react, react-hook-form + zod. Node 22.

Шрифты: Golos Text и JetBrains Mono через `next/font/google` (сеть к fonts.googleapis.com из окружения доступна; в сборке шрифты скачиваются и вшиваются). Unsplash и mdmt.ru из окружения недоступны — **стоковых фото не будет**, всё визуальное строим сами.

## Фазы

### Фаза 0 · Документация (текущая)
`docs/01-BRIEF`, `02-DESIGN`, `03-PLAN`, `DECISIONS`, `CLAUDE.md`. Выход: согласование решений из `DECISIONS.md`.

### Фаза 1 · Основа
- Инициализация Next + Tailwind `@theme` + шрифты + Lenis↔ScrollTrigger + `prefers-reduced-motion`-хук.
- `/content/*.ts` (site, series, stages, projects, reviews, services, credits) с типизированными данными и заглушками.
- `typograph()`, `placeholder()`-компонент для `[…]`.
- `/styleguide`: токены, типографика, кнопки (магнитные), карточки, бейджи, поля, заглушки, размерные линии.
- Готово, когда: styleguide выглядит как продукт, сборка `out/` проходит.

### Фаза 2 · Генератор фермы и 3D-ядро
- `lib/truss/buildTruss.ts`: все 7 сечений, параметры серии (условные пропорции), длина.
- `components/three/Truss.tsx` (инстансинг), сборка с эмиссионными вспышками, свет-рига.
- SVG-изометрия той же фермы (фолбэк и прелоадер), скрипт рендера постера для мобильных.
- Готово, когда: ферма красиво вращается на 60 fps в headless-Chromium со swiftshader (снимки кадров), геометрия строится для каждой комбинации серия×сечение.

### Фаза 3 · Главная — первый экран (самое важное)
Прелоадер-чертёж, шапка, hero с 3D и маской заголовка, тикер проектов, факты (count-up). Мобильный постер + «Покрутить в 3D».
Готово, когда: первый экран на 390 и 1440 px выглядит «дорого», LCP-текст виден сразу без ожидания 3D.

### Фаза 4 · Сцены на скролле
Сборка/разборка фермы (pin 250 %), Геленджик Арена (pin 200 %), схемы СК-1/2/3. Мобильные облегчённые версии.

### Фаза 5 · Конфигуратор, каталог, заявка
Конфигуратор R3F (с фолбэком), каталог с фильтрами и URL-параметрами, форма расчёта (`mailto:` info@mdmt.ru + Telegram), состояние успеха «галочка-чертёж».

### Фаза 6 · Остальные секции главной
Производство и сертификаты (3 карточки-заглушки с «подъёмом листа»), «Также производим», отзывы (реальные цитаты), CTA на оранжевом «жаре», футер со штампом и меткой концепта.

### Фаза 7 · Внутренние страницы
`/catalog`, `/catalog/[series]` (7 статических), `/stages`, `/projects`, `/projects/gelendzhik-arena` (полный), шаблон остальных, `/production`, `/rfq`, `/contacts`, `/privacy`, `404`. Делаем компактно на общих компонентах.

### Фаза 8 · Полировка и приёмка
Playwright-проход по 360/390/768/1024/1440/1920, Lighthouse mobile, клавиатура/фокус, reduced-motion, noindex + robots, OG-картинка (генерируем сами), `README.md`, `npm run placeholders`, деплой-настройки (Cloudflare Pages основной, GitHub Pages резерв).

## Проверка «на глаз» (обязательна на каждой фазе)

Playwright-скриншоты на 390 и 1440 px, для скролл-сцен — серия кадров на 0/25/50/75/100 % прогресса. Смотрим сами и правим, пока не станет «хорошо», а не «работает». WebGL в headless: запуск Chromium с `--use-gl=angle --use-angle=swiftshader --enable-unsafe-swiftshader`. Реальный FPS на железе тут не померить — закладываем деградацию (`PerformanceMonitor`) и снижаем сложность на мобильных.

## Риски

| Риск | Что делаем |
|---|---|
| Тяжёлый 3D на слабом телефоне | постер + запуск по тапу, ≤ 2 WebGL-контекста, инстансинг, деградация dpr/постпроцессинга |
| Конфликт Lenis / ScrollTrigger / R3F | один источник прогресса скролла в контексте, `frameloop="demand"` + `invalidate()` из ticker |
| `output: 'export'` ограничения | без API routes, `images.unoptimized`, `trailingSlash: true`, динамические маршруты через `generateStaticParams` |
| Выдуманные данные | поля `null` → видимая заглушка; скрипт `placeholders` перечисляет все |
| Фото недоступны | собственная 3D/SVG-графика, плейсхолдер-плёнка |
| Первое впечатление ломается при медленной сети | текст hero и постер отдаются в HTML, 3D догружается лениво |

## Определение «готово» (приёмка)

Чек-лист Б10 из промпта плюс три субъективных вопроса: (1) хочется ли досмотреть hero до конца сборки; (2) верит ли инженер, что сайт делали люди, которые знают фермы; (3) показался ли бы он стыдным рядом с сайтами крупных брендов — если да, возвращаемся в фазу.
