# CLAUDE.md — сайт-концепт МДМ-Технология

Концепт сайта для ООО «МДМ-Технология» (алюминиевые фермы и сцены, Москва). Цель — произвести сильное визуальное впечатление. Не официальный сайт; noindex.

Документация: `docs/01-BRIEF.md` (факты), `docs/02-DESIGN.md` (дизайн), `docs/03-PLAN.md` (план), `docs/DECISIONS.md` (решения). Исходный промпт «Алексей-3.1» — источник правды по требованиям.

## Правила

- Стек: Next.js 16 (`output: 'export'`), TS strict, Tailwind v4 (`@theme`), R3F + drei, GSAP/ScrollTrigger, Lenis, motion. Без бэкенда.
- Весь текст — в `/content`. Ничего не выдумывать: неизвестное — видимая заглушка `[... — уточнить]`.
- Обращение «Вы» с заглавной. Текст из `/content` проходит через `typograph()`.
- Анимируем только `transform`/`opacity`; обязателен `prefers-reduced-motion`.
- Не более двух WebGL-контекстов; на мобильных 3D стартует по тапу.
- Нет чужих логотипов, нет сравнений с конкурентами по имени, нет цен и нагрузок.
- После каждой секции — скриншоты 390 и 1440 px (Playwright) и честный просмотр.

## Команды

`npm run dev` · `npm run build` (→ `out/`) · `npm run placeholders` (список заглушек)
